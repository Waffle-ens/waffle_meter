# 음성 팩 원본 (voice pack sources)

`../와순이/`, `../와붕이/`의 클립을 만들어 낸 **레퍼런스 음성**이다. 이 wav가 곧 목소리의 정의이고,
잃어버리면 같은 목소리를 다시 만들 수 없다 — 새로 뽑으면 다른 사람 목소리가 된다.

`.csproj`는 `Assets/voice/**/*.mp3`만 싣는다. 이 폴더의 wav는 배포판에 나가지 않고 저장소에만 남는다.

## ⚠ 레퍼런스가 지켜야 할 두 가지

둘 다 2026-08-24 에 실측으로 알아낸 것이고, **첫 굽기(v2.11.0)는 둘 다 어겼다.**

**1. 완결 평서문이어야 한다.** 복제 모델은 레퍼런스의 억양 스타일까지 복사한다. 옛 와순이 레퍼런스
`감시자 카이라, 10분 뒤 정각 출현 가능`은 명사로 끝나는 조각이라 종결 하강이 없었고(끝기울기 **+16.2**,
즉 올라간다), 그 버릇이 팩 420줄에 그대로 옮았다 — 문장 끝이 올라가는 줄이 **60개**였다. 와붕이
레퍼런스는 완결 평서문이고(끝기울기 −21.3) 억양 편차가 절반이다. 레퍼런스를 하강 종결로 바꾸자
같은 지표가 60 → 6 으로 떨어졌다.

**2. 팩의 어떤 문구와도 겹치면 안 된다.** 겹치면 **그 줄만** 음색이 어긋난다. 옛 와순이는 레퍼런스
텍스트가 팩 문구와 글자까지 같아서(`감시자 카이라, 10분 뒤 정각 출현 가능`) 그 한 줄이 팩 중심에서
z=+2.1 로 튀었다. 와붕이는 마침표 차이로 살짝 어긋나 있어 z=−0.4, 정상이다. 새 레퍼런스 문장은
팩 420줄과 부분 포함까지 대조해 고른다.

## 재생성 방법

엔진: **Qwen3-TTS 12Hz 1.7B Base** (Apache-2.0), 로컬 실행. 음색은 레퍼런스가 고정하고, 발음·억양은
샘플링이 정한다 — 그래서 레퍼런스만 있으면 문구가 늘어나도 같은 목소리로 이어붙일 수 있다.

| | 와순이 | 와붕이 |
|---|---|---|
| 레퍼런스 | `와순이.wav` (7.91s) | `와붕이.wav` (2.62s) |
| 레퍼런스 텍스트 | `준비가 끝났습니다. 곧 시작하겠습니다. 자세한 내용은 화면에서 확인하실 수 있습니다.` | `슈고 페스타. 5분 뒤 시작합니다.` |
| 배속 | 굽기 뒤 `atempo=1.10` | 없음 |

- `ref_text`는 **레퍼런스 오디오를 그대로 옮긴 것이어야 한다.** 실제 발음과 다른 글자를 넣으면 문맥이
  오염된다(와붕이 쪽에 마침표가 남아 있는 것은 그 오디오가 실제로 그렇게 끊겨 읽히기 때문이다).
- 생성 파라미터: `temperature=0.65`, `top_p=0.8`. 라이브러리 기본값 0.9는 느슨해서 한국어 예사소리가
  된소리로 새는 일이 잦았다(`전선`→`쩐선`, `근성`→`끈성`). 낮추면 음색은 그대로고 발음만 표준 쪽으로 좁는다.
  이 값은 Gradio API 파라미터가 아니라 Pinokio 앱 `app/app.py` 를 직접 고쳐 넣은 것이다 — 앱을
  업데이트하면 날아가므로 굽기 전에 확인할 것.
- **말속도는 레퍼런스를 따라가지 않는다.** 레퍼런스를 1.16배로 늘려 복제해 봤더니 산출물이 오히려
  미세하게 느렸다. 속도는 굽고 나서 `atempo` 로 맞춘다(음높이는 그대로 두고 시간축만).

## 와순이 목소리의 계보 (2026-08-24)

세 파일이 한 줄로 이어진다. 다시 만들 일이 생기면 이 순서를 따른다.

1. `와순이-씨앗-voicedesign.wav` — VoiceDesign 1.7B, seed **666**. 묘사는 아래 요지에 억양·조음
   지시를 더한 것: *K-pop 아이돌의 정돈된 음색을 가진 20대 후반 한국 여성, 낮은 중음역, 따뜻하고
   생기 있게. 그룹 메인보컬이 카메라를 보고 말하는 정돈된 톤.* + **"원어민이 평서문을 읽듯 끝을 내려라,
   의문이나 낭독조로 올리지 말 것"**, **"자음은 부드럽고 힘을 빼라, 긴장시키거나 굳히지 말 것"**.
   억양 지시는 첫 굽기 때 아예 없었고, 그게 억양이 흔들린 한 원인이었다.
2. `와순이.wav` — 위를 레퍼런스로 삼아 위 표의 긴 문장을 **복제**해 낸 것(seed 555). 복제는 음색을
   옮기는 작업이라 씨앗의 목소리가 그대로 따라온다. VoiceDesign 에 다른 문장을 주면 목소리 자체가
   바뀌지만(실측: 음높이가 눈에 띄게 내려갔다) 이 방법은 안 바뀐다.
3. `와순이-v2.11.0-폐기.wav` — 이전 목소리의 레퍼런스. 위 두 규칙을 어긴 물건이라 더는 쓰지 않지만,
   그 목소리로 구운 클립을 다시 손볼 일이 있을까 봐 남겨 둔다.

## 후보 고르는 법 (굽기 스크립트)

줄마다 시드 5개(한글 3음절 이하는 `네, ` 접두 후보 2개 추가)를 만들고 **이 순서로** 거른다.
순서가 중요하다 — 억양만 보고 골랐더니 된소리가 새는 줄이 5→13 으로 늘었다.

1. 길이가 정상 범위인 것만 (폭주 배제 — 한 문구에서 163초짜리를 뱉은 적이 있다)
2. **Whisper 전사 유사도가 그 줄 최고치의 0.08 이내인 것만** ← 발음
3. 그중 끝이 내려가는 것 (`end_slope < 0`)
4. 남은 것 중 억양 z-거리가 최소인 것

⚠ **Whisper 전사를 합격 판정에 쓰지 말 것.** 게임 고유명사를 몰라 멀쩡한 클립을 엉뚱하게 옮긴다.
같은 문구의 후보들 사이 **순위**를 매기는 데까지만 쓴다.

⚠ **F0(음높이) 추정값을 근거로 쓰지 말 것.** 300Hz 근처에서 자기상관 추정기가 옥타브 오류를 낸다
(피치를 1.04배 올린 파일을 "내려갔다"고 보고했다). 낮은 음역(와붕이 102Hz)에서는 맞는다.
음높이를 다뤄야 하면 절대값 대신 **반음 단위 시프트**로 조작하고 귀로 확인한다.
- 파일명 = `sha256(발화문구)[:16] + ".mp3"`. 앱이 문구로 직접 해시를 떠서 찾으므로 매핑 테이블이 없다.
  `BakedVoicePack`(C#)과 굽기 스크립트(Python)가 같은 값을 내는지는 `BakedVoicePackTests`가 지킨다.

## 무엇을 구워야 하는지는 물어봐서 알아낸다

굽기 목록의 **정본은 `ShippedVoicePackTests`**다 — 앱이 말할 수 있는 문구를 앱과 같은 규칙으로
재구성해 팩과 대조한다. 목록을 손으로 뽑아 쓰려면 로컬 도구
`dotnet/tools/voice-lines-export.py`(굽기 스크립트와 마찬가지로 저장소에 싣지 않는다)를 쓴다:

```
python dotnet/tools/voice-lines-export.py            # 요약
python dotnet/tools/voice-lines-export.py --missing  # 안 구워진 줄만 (굽기 입력)
```

두 구현의 결과가 갈리면 그건 규칙이 바뀌었다는 신호다.

**처음 구울 때 이 목록을 잘못 잡았다.** `buff_catalog.json`(큐레이팅 70개)에서 뽑았는데, 버프 피커가
실제로 나열하는 건 `buff_names.json` + 런타임에 관측된 코드다. 그래서 피커에서 음성을 켤 수 있는 이름
362개 중 52개만 클립이 있었고 나머지는 전부 조용히 온라인으로 떨어졌다 — 살성 `환영 분신`이 그 예다.
카탈로그는 "관측 전에도 미리 띄울 목록"이지 "말할 수 있는 목록"이 아니다.

**지금은 전부 구워져 있다(420/420, 고아 0).** 그래서 `unbaked.txt`가 없다 — 새 구멍이 생기면
테스트가 그냥 빨개진다.

한 번에 다 못 채울 때만 `unbaked.txt`를 만든다(`--write-baseline`). 봐준 목록이 아니라 갚아야 할
목록이라, 이미 구운 줄이 남아 있거나 앱이 더 이상 말하지 않는 줄이 남아 있으면 테스트가 잡는다.
다 갚으면 파일을 지워서 다음 구멍이 조용히 등재되지 않게 한다.

## 문구가 늘어나면

게임 패치로 필드보스나 버프가 추가되면 그 줄만 새로 구워 넣으면 된다. 시드를 고정하면 결과가 비트 단위로
재현되므로 기존 클립과 어긋나지 않는다.

읽는 소리가 표기와 다른 이름은 `SpokenName`에 등록하고 **그 읽는 소리로** 구워야 한다. 등록만 하고
굽지 않으면 그 줄은 조용히 온라인 음성으로 떨어진다.

굽지 못한 줄을 읽는 온라인 목소리는 `BakedVoicePack.OnlineVoiceFor`가 고른다 — 팩을 흉내내지는
못해도 성별은 맞춘다(와순이=SunHi 여성, 와붕이=InJoon 남성). 예전에는 어느 팩이든 여성으로 읽어서,
클립이 없다는 사실이 "늦게 나온다"가 아니라 "사람이 바뀐다"로 들렸다.

## 굽기 중에 확인된 것

- **문장 첫머리에서 첫 음절이 겹치는 일이 있다.** `경계의 방랑자 파르곤`은 시드를 15번 넘게 바꿔도
  `경경계의`로 나왔고 표기를 바꿔도 소용없었다. 앞에 `네, `를 붙여 생성한 뒤 첫 무음 경계에서 잘라내면
  사라진다 — 모델이 더듬을 자리를 만들어 주고 그 부분을 버리는 것이다.
- **3음절 이하 짧은 줄은 불안정하다.** 레퍼런스가 긴 문장인데 타깃이 극단적으로 짧으면 무너진다.
- **Whisper 전사는 판정에 쓸 수 없다.** 게임 고유명사를 모르기 때문에 멀쩡한 클립도 엉뚱하게 옮긴다.
  후보 순위를 매기는 데까지만 쓰고, 합격 여부는 사람이 들어서 정했다.
