# 아직 굽지 않은 문구 (unbaked lines)
#
# 이 파일은 '봐준 목록'이 아니라 '갚아야 할 목록'이다. ShippedVoicePackTests 가 앱이 말할 수 있는 문구
# 전체와 팩의 내용을 대조하는데, 클립 렌더링은 로컬 음성 모델이 있어야 하므로 한 번에 다 채울 수 없다.
# 그동안 테스트를 빨간 채로 두면 새로 생긴 구멍(문구 변경·직업 추가)을 아무도 못 보게 되므로,
# 지금 아는 구멍만 여기 고정하고 그 밖의 누락만 실패시킨다.
#
# 한 줄을 구우면 이 파일에서 지운다 — 이미 구워진 줄이 남아 있으면 테스트가 잡는다.
# 문구가 바뀌어 앱이 더 이상 말하지 않게 된 줄이 남아 있어도 테스트가 잡는다.
#
# 재생성: python dotnet/tools/voice-lines-export.py --write-baseline
# 현재 213줄 (문구 711개 중).
